# adielrios

Grupo Nutrindo Emoções · by Adiel Ríos

Este repositório abriga dois sistemas independentes.

## `clinica/` — GNE Clinical OS

O sistema operacional clínico: 12 sistemas centrais, Command Center, motor Next Best Action, 33 indicadores, 11 agentes de IA com guardrails, controle de acesso por perfil e trilha de auditoria append-only.

→ [`clinica/README.md`](clinica/README.md) para abrir e operar
→ [`docs/`](docs/) para a arquitetura, os processos, os indicadores e a implantação

Abrir: `cd clinica && python3 -m http.server 8080`

## `index.html` — Sistema Modo Deus

Sistema de conteúdo e marketing, anterior e independente. Preservado sem alterações.
